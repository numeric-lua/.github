# Supporting numeric-lua

numeric-lua is free software under BSD-3-Clause. Donations are optional: no
feature is paywalled, no build is held back, and there are no ads or trackers.

## Other ways to help

- Star the repositories and report bugs with logs; that is useful work too.
- Open an issue for paid support or a specific integration.
- If you have a Ko-fi, Liberapay, Open Collective, or Pix account, it can be
  added to the funding files with the other entries.

Money, when it exists, goes to hardware, hosting, and development time — not to
closing the source.
